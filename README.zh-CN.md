## 安装

这是源码 Demo，附带必要角色 SVG 和四段声音参考，总计 13.29 秒；大型模型、Python 环境和 Ollama 不在源码包里，首次安装时另行下载。下载位置并不改变第三方素材的权利状态。

开发验证配置为 Windows 11、RTX 4060 Laptop 8GB、24GB 内存、Python 3.12.15；这不是经过测量的最低配置。建议预留约 35GB 可用空间，将项目解压到 D 盘，例如 `D:\Projects\CharacterForge-Demo`。源码只有几 MB，不能因此认为运行模型只需要几 MB 或适合低配置嵌入式硬件。

电脑需要 Windows x64 Python 3.12。不会卸载原来的 Python 或修改显卡驱动。在项目文件夹地址栏输入 `cmd`，依次运行：

```bat
py -3.12 setup_demo.py install
py -3.12 setup_demo.py models
py -3.12 run.py check
py -3.12 run.py start --wait
```

第一步安装独立文字、语音环境；第二步按固定上游版本下载模型并校验 TTS 文件；第三步检查文件；第四步启动。首次下载和安装比较久，需要联网。之后运行可以离线，不使用付费 API。安装中的缓存和临时文件保存在项目目录。

默认作者 3B 不需要 Ollama；如果还想用界面里的 8B 选项，再运行：

```bat
py -3.12 setup_demo.py ollama
py -3.12 setup_demo.py 8b
```

也可运行 `py -3.12 setup_demo.py all` 安装两种后端。首次模型和工具下载可能超过 10GB，两个 CUDA 环境另占磁盘。`qwen3:8b` 标签可能随上游变化；HF 模型固定 revision，Ollama 安装包固定 SHA256。完整全新下载流程尚未在另一台干净电脑上实测，不能把安装脚本写好当作已通过这一验收。

## 使用

安装后双击 `Start Demo.cmd`，浏览器打开 http://127.0.0.1:7862/ 。先用文字发一句英语，再开启麦克风。语气默认自动判断，仍保留手动试听。停止时用 `Stop Demo.cmd`。如果旧版占用相同端口，先用旧版自己的停止入口退出；新入口不会接管其他版本。

人物、声音参考和克隆能力均保留，不以系统声音或另一个角色替换。给 WAV 添加版权信息后，PCM 样本逐字节相同；给 SVG 添加声明不改变图形。声音参考来源和哈希见 `config/asset-provenance.json` 与音频旁的 JSON。

聊天、记忆、录音和日志由你本机生成，不在仓库里。不要把 `.local`、`data`、缓存、环境、模型或本机配置整体上传。程序只连接本机回环地址。
